#### **Dijkstra's Algorithm Visualization**:

This project is a Python implementation of **Dijkstra's algorithm** with real-time visualization using **Pygame**. It demonstrates how the algorithm finds the shortest path between two nodes in a graph. The program allows users to input start and end nodes, and it visually animates the process of exploring the graph, updating distances, and highlighting the shortest path.

#### **Key Features**:
- Interactive visualization of Dijkstra's algorithm.
- Step-by-step animation of graph exploration and pathfinding.
- User-friendly interface to input start and end nodes.
- Displays the shortest path and its total distance.

#### **Tech Stack**:
- Python
- Pygame (for visualization)

#### **How It Works**:
1. The graph is predefined with vertices and weighted edges.
2. The user selects a start and end node.
3. The algorithm runs, and the visualization shows:
   - Visited nodes.
   - Current node being processed.
   - The shortest path in red.
4. The shortest path and its distance are printed in the console.
